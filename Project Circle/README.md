# Circle

흰 캔버스에서 개념·메모·해시태그를 정리하는 웹 앱입니다. 프레임워크 및 빌드 과정 없이 실행합니다.

## 실행

`npm run dev` → http://127.0.0.1:4173

`npm run check`로 JavaScript 구문을 검사합니다.

## Firebase 연결

1. Firebase Console에서 프로젝트와 웹 앱을 생성합니다.
2. Authentication → Sign-in method에서 이메일/비밀번호를 활성화합니다.
3. Cloud Firestore 데이터베이스를 생성합니다. 공개 테스트 규칙 대신 이 저장소의 `firestore.rules`를 배포하세요.
4. Firebase 콘솔 → 프로젝트 설정(톱니바퀴) → 일반 → 내 앱 → 웹 앱 → SDK 설정 및 구성에서 `firebaseConfig`를 찾습니다. 웹 앱이 없으면 `</>` 버튼으로 먼저 등록합니다. `circle/config.js`의 `window.CIRCLE_FIREBASE_CONFIG = null;`에서 `null`을 해당 설정의 `{ ... }` 전체로 바꿉니다. `apiKey` 하나만 넣는 것이 아닙니다. `const firebaseConfig =`나 `initializeApp(...)` 줄은 복사할 필요가 없습니다. 각 값은 콘솔에서 그대로 복사하고 서비스 계정 JSON이나 `private_key`는 넣지 마세요.
5. Firebase Authentication의 승인 도메인에 사용하는 사이트 도메인과 로컬 개발용 localhost를 추가합니다.
6. Firebase CLI를 사용하는 경우 `firebase use --add`로 프로젝트를 선택하고 `firebase deploy --only firestore:rules`를 실행합니다. Firebase Hosting에 게시하려면 `firebase deploy --only hosting`을 실행합니다.

설정이 없으면 로그인 기능은 비활성화되며 체험 모드만 제공합니다. 체험 데이터는 브라우저 localStorage에 저장됩니다. 실제 계정 데이터로 자동 이관되지 않습니다. Firebase CDN 접근이 필요합니다.

## 동작

- 로그인/회원가입 → 폴더형 프로젝트 목록 → 개념 지도.
- 원 드래그, 캔버스 드래그, 커서 중심 휠 확대·축소, 전체 보기.
- 개념 검색으로 카메라 이동, #태그 검색으로 해당 원 연결 및 화면 맞춤. 검색 외 원은 흐림 처리.
- 원 클릭 또는 키보드 Enter로 메모·태그·색상·크기 편집. 저장 버튼으로 확정.
- 색상 패널 또는 R·G·B(각각 0~255) 입력으로 임의의 색상 선택. 어두운 원에는 밝은 글씨를 적용합니다. 변경한 `firestore.rules`도 배포해야 사용자 지정 색상을 계정에 저장할 수 있습니다.
- 빈 캔버스를 클릭하면 편집 창이 닫힙니다. 저장하지 않은 변경이 있으면 닫기 전에 확인합니다. 빈 캔버스 드래그는 화면 이동 동작을 유지합니다.
- Firebase onSnapshot으로 프로젝트와 개념의 변경 사항을 실시간 수신.
- 개념 위치와 내용을 별도로 갱신하여 다른 원 편집 및 위치 이동이 전체 지도를 덮어쓰지 않습니다. 같은 개념의 같은 필드를 동시에 저장하면 마지막 저장이 적용됩니다.
- 소유자가 128비트 난수 초대 코드를 생성합니다. 재생성하면 이전 코드가 만료됩니다. 로그인 사용자가 코드로 참여하면 읽기·편집 권한을 받습니다. 최대 100명.
- Firestore 규칙으로 비회원 접근, 타 사용자 소유권 변경, 초대 코드 목록 조회를 차단합니다.

## 검증 범위

Firebase 설정이 제공되지 않은 상태에서는 실제 인증, Firestore 권한 및 여러 계정의 동기화를 검증할 수 없습니다. 운영 전 별도 두 계정으로 프로젝트 참여, 실시간 변경, 코드 재발급 및 비회원 접근 거부를 검증하세요. HTML은 사용자 입력을 이스케이프하며 메모는 일반 텍스트로 표시합니다.
